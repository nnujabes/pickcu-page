영양 편의점

평소 말투로 조건을 한 줄 적으면, CU 편의점 상품 조합 Top 5를 가격과 영양 합계와 함께 추천합니다. LLM은 문장을 해석만 하고, 숫자는 실제 상품 DB로 코드가 계산합니다.

“운동 끝나고 5천원으로 먹을 거 추천해줘” 간편식사음료 → 단백질 ↑지방 ↓예산 5,000원 → 조합 Top 5
화면 보기 결과 숫자 GitHub 저장소

문제

편의점에서 목적과 예산에 맞는 먹거리를 고르려면 영양성분표를 하나하나 보고, 여러 상품의 합계를 직접 계산해야 합니다.

운동 후 · 예산

“운동 후 먹을 1만 원 미만의 음식을 추천해줘”

초저예산 식단

“5000원으로 든든한 한 끼 추천해줘”

야식 · 성분 관리

“내일 얼굴 안 붓게 짠 거 말고 야식 추천해줘”

기존 서비스로는 안 되는 것

목적, 예산, 정확한 영양 합계를 한 번에 주는 서비스가 없었습니다.

서비스할 수 있는 것한계영양 편의점
편의점 자체 앱자사 상품·행사·재고 조회목적별 조합 추천과 영양 합산이 없음목적·예산에 맞는 조합과 영양 합계
범용 LLM 챗봇자연어로 조합 추천실제 제품·가격·영양을 추정(환각)LLM은 해석만, 수치는 DB·코드가 계산

식단 기록 앱직접 검색 후 기록구매 전 선택은 지원하지 않음메뉴 고르기 전에 바로 추천

해결 방법과 데모

사용자는 카테고리를 1~3개 고르고 문장을 씁니다. 결과로 상품 조합 5개를 받고, 영양정보 확인, 장바구니, 별점까지 한 화면에서 이어집니다.

1

조건 입력

카테고리를 고르고 평소 말투로 문장을 입력합니다.

2

Top 5 결과

조합마다 가격, 단백질·열량·지방 합계가 붙어 나옵니다.

3

영양정보 확인

상품 사진에 마우스를 올리거나 누르면 6대 영양정보가 나옵니다.

4

장바구니 담기

마음에 드는 조합을 담고 합계 금액을 확인합니다.

5

별점 남기기

추천받은 조합에 별점과 한 줄 평을 남기면 랭킹에 오르고, 다음 추천 순위에 반영됩니다.

다크·화이트, 웹·모바일

다크 모드 · 기본 테마, 민트색 강조

화이트 모드 · 노란색 강조, 버튼 하나로 전환

시연 시나리오

운동 후 먹을 1만원 미만의 음식을 추천해줘 오늘 날씨 어때? (관계없는 문장은 추천하지 않음) 500원으로 든든한 한 끼 추천해줘 (예산이 너무 적으면 안내) 내일 얼굴 안 붓게 짠 거 말고 야식 추천해줘

작동 원리

데이터를 먼저 만들고, 추천할 때는 LLM이 문장을 조건으로 바꾼 뒤 코드가 실제 DB로 조합을 계산합니다.

① 데이터 구축

INCU 상품 이미지앱 상세 페이지 크롤링
→
VISION LLMQwen2.5-VL-7B영양성분표 → JSON
→
DBSQLite 상품 DB2,154개 · 영양소 6개 · 가격 · 행사

② 추천 서비스

IN문장 + 카테고리1~3개 선택
→
LLMA.X-4.0-LightQLoRA 파인튜닝 · 영양소 2개와 방향
→
CODE · SQL후보 검색카테고리별 · 예산은 규칙으로 가격 상한
→
CODETop 5 필터영양 0.7 + 가격 0.3 · 별점 반영
→
OUT추천 카드 5개합계 가격 · 영양 합계

LLM은 문장을 해석만 합니다. 가격과 영양 합계는 모델이 지어내지 못하도록 Python과 SQL이 DB 값으로 계산합니다.

예시: “운동 끝나고 5천원으로…” + 간편식사·음료

관계없는 문장 거르기

모델이 “오늘 날씨 어때”에도 영양소를 지어내는 문제가 있었습니다. 재학습 없이 규칙 검사와 시스템 프롬프트 두 단계로 막아, 잡담 6문장을 모두 걸렀습니다(수정 전 1문장). 인사·요청어 13문장도 모두 걸렀고, 정상 문장 정확도는 dev 86.1%에서 85.6%로 1문장만 바뀌었습니다.

한계와 다음 단계

아직 안 되는 것

  • 카테고리까지 문장으로 처리하려던 계획은 시간 문제로 구현하지 못해, 화면에서 직접 고르는 방식으로 남겼습니다.
  • 학습을 충분히 더 진행하지 못해 모델 성능을 더 끌어올릴 여지가 있습니다.
  • 상품 DB는 CU 한 곳의 상품만 담고 있습니다.

다음에 할 것

  • 안정적인 서버 환경에서 카테고리도 문장 한 줄에서 함께 뽑도록 확장하고, 학습 데이터를 늘려 다시 학습합니다.
  • CU 외 다른 편의점으로 영양 DB를 넓힙니다.
  • 알레르기, 건강 목적 같은 조건을 추가합니다.
